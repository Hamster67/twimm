# Taiwan in my mind!（TWIMM）— 飛天車環島

版本：**1.0 Beta (4)**

社群：[Threads](https://www.threads.com/@twimm_official_tw)・[Discord](https://discord.gg/SQmFgakrUf)・[Instagram](https://www.instagram.com/twimm_official_tw)

單一網頁 3D 遊戲（Three.js）。**直接點擊 [連結](https://twimm.netlify.app) 即可遊玩**

## 玩法
- **故事模式：** 2027/01/01 08:00 從**花蓮火車站**出發，開著火箭飛天車「TWIMCAR R1」**環島一圈**，經過 29 個點（早餐店、特技表演、**東大門夜市**、七星潭、池上、南迴、墾丁、高雄、台南、阿里山、台中、新竹、桃園、台北 101、**頭城烏石港（龜山島）、礁溪溫泉、宜蘭幾米廣場、蘇澳冷泉、清水斷崖**…），最後回到**花蓮火車站衝過終點線**。開新旅程時可以選**往南**或**往北**出發。主角稻撤入庫（日本賽車手）與好友露邊挺徹同行。沒有暴力、沒有犯罪、沒有警察追逐。
- **跟著走：** 畫面上的綠色光柱 + 上方導航列（方向箭頭與距離）+ 小地圖（綠線＝前往下一點的路）。
- **新手訓練：** 在南迴公路上練習，14 步：巡航、山路彎道、**看綠色光柱**、倒退、回儲存點、火箭、起飛、Tab 緩衝、甩尾、光圈、巨型坡道、停車、**下車找人蓋章**、回到車上（對應故事裡的三場特技表演）。不存檔、時間固定早上 10 點，T 跳過一步；訓練中不能離開南迴公路。
- **第一次玩：** 沒有存檔時按「開始新旅程」會先進行新手訓練，結業後直接從花蓮出發。有存檔時主選單最上面、高亮的是「繼續旅程」。
- **環島完成後：** 可以自由飛行、「再玩一次環島」，或回主選單。
- **隱藏彩蛋：** 地圖上沒標的地方也值得下車逛逛……

## 按鍵
| 按鍵 | 功能 |
|---|---|
| W / S / A / D | 油門（只按 W 約 200 km/h）/ 煞車倒車 / 轉向 |
| Shift | 火箭推進 |
| Tab（空中長按） | 緩衝落地，效果跟 Space 一樣但噴白煙、而且不限時 |
| Space | 起飛（上限約 45 m） |
| Tab（長按） | 空中緩衝落地；在坡道/牆面上脫離 |
| **Enter / 小鍵盤 Enter** | **倒退 5 秒**（最多退到儲存點） |
| **R（短按）** | 回到儲存點正中央 |
| **R（長按約 1 秒）** | 存下最近 30 秒影片 |
| F | 在休息站下車 / 回車上（跑的時候不行，下車時時間暫停） |
| E | 與觀眾、店家對話（可蓋章） |
| C / V | 切換視角 / 第一視角 |
| T / Enter | 跳過過場動畫 / 特技表演 |
| Y | 回看最近畫面（多視角重播，可輸出 webm） |
| P / Esc | 暫停（Backspace 回主選單） |
| **O** | **設定（畫質・聲音）**，主選單也有「設定」按鈕 |
| **P / Esc** | 暫停 ＝ 設定選單（同一個畫面，可繼續遊戲或存檔回主選單） |
| **B** | 車內音響：Spotify／YouTube 連動（貼連結）／本機音檔／內建電台 |
| **Z** | 睡覺（20:00～00:00 可用，車子先停下再睡到隔天 08:00） |
| **N** | 放大／縮小台灣島嶼地圖；放大後**點藍色的點**＝傳送回那個蓋過章的地方 |
| **U** | 隱藏／顯示畫面上的介面（GUI） |
| **F2** | 截圖（存成 PNG，不含介面） |
| 右鍵拖曳 | 轉動視角（放開後回正） |

## 系統
- **時間：** 真實 5 秒 ＝ 遊戲 1 分鐘（一天約 2 小時）；左上角顯示日期時間與**累計遊玩計時**（真實時間，1 分鐘＝1 分鐘）（只有新遊戲才會歸零）。白天 12–16 點人最多，晚上變少；**午夜 12 點車子自動停下（空中會等落地），自動睡到早上 8 點**。
- **天氣：** 會隨遊戲時間下雨（山區機率較高），有雨絲、陰暗天空與雨聲；設定裡可改成永遠晴天／永遠下雨。
- **環境音：** 鳥叫 05–18 點、蟬叫 08–17 點、夜鷺 19–05 點；自備音檔放在 `sounds/`，見 `sounds/README.txt`。
- **地圖：** 整圈約 74 公里（台北 → 新北 → 雪山隧道 → 蘭陽平原 → 宜蘭 → 蘇澳 → 蘇花改 → 花蓮約 24 公里），大城市街道較密、外圍也有一排排房子；花東縱谷與蘭陽平原有大片稻田與農舍；山上有隧道（裡面有燈），雪隧、蘇花改都有長隧道；阿里山有一座大瀑布；宜蘭外海看得到龜山島；太平洋那側是乾淨的海平線。
- **火車（可以搭）：** 鐵路沿著整座本島繞一圈，普悠瑪（順行）與區間車（逆行）一直在跑，會停靠車站；山區、海岸斷崖、大城市的路段在地底下／隧道裡（看得到火車鑽進隧道口）。車站在路的左側：**花蓮、池上、台南、新竹、宜蘭**（不是任務點）。下車走到售票機按 **E**：選目的地 → 投幣買票 → 刷票進站 → 月台候車 → 列車進站按 E 上車 → 乘車（C 切換車窗／車外視角，Enter 快轉）→ 到站，飛天車會停在車站前面。
- **飛機（可以搭）：** **台北松山、桃園、台中清泉崗**三座機場在路的右側（不是任務點），經過時看得到飛機起降。走到航廈入口的櫃台按 **E**：選航班（**澎湖 馬公／金門 尚義**）→ 報到・行李托運（拿到登機證）→ 安全檢查 → 證照查驗（護照蓋章）→ 貴賓室（點珍奶、牛肉麵…等登機廣播）→ 登機門掃描登機證 → 起飛、巡航、降落。
- **離島：** 澎湖（天后宮、雙心石滬、玄武岩、跨海大橋、風車、仙人掌冰）、金門（莒光樓、風獅爺、閩南古厝、坑道、高粱田、貢糖）可以步行觀光、跟當地人聊天；回到機場櫃台按 E，可以選擇飛回松山、桃園或台中。
- **安全：** 車與人分隔（護欄/人行道），車禍不會爆炸；撞到東西或出界會觸發**倒退特效**。
- **相簿：** 主選單 →「相簿」可回看長按 R 存下的影片（存在瀏覽器 IndexedDB，最多 12 段）。
- **存檔：** 自動存檔（休息站、蓋章、每 ~1 公里），主選單「繼續旅程」。

## 管理員（除錯）
在瀏覽器 console 輸入 `op` 解鎖（本次不存檔）。暫停選單會多出管理員區塊：調整時間、時間速度、無敵，以及「**完成所有任務（可任意傳送）**」；console 也可用 `admin.completeAll()`。

## 開發
原始碼在 `src/`，執行 `python build.py` 會把 `src/template.html` 與 `src/[0-9]*.js` 合併成 `index.html`。

| 檔案 | 內容 |
|---|---|
| `00_core.js` | 引擎：車輛/飛行/坡道/爬牆/重播/音效/曼哈頓（訓練場） |
| `10_tw_world.js` | 台灣路線、地形、區塊串流、場景 |
| `11_tw_landmarks.js` | 夜市與各景點建築 |
| `20_tw_systems.js` | 時鐘/日夜/人潮/交通/夥伴/倒退/出界/睡覺/存檔 |
| `25_story_data.js` | 對話與路上事件 |
| `26_tw_train.js` | 火車模組（台鐵普悠瑪／區間車，沿著整座本島繞圈） |
| `27_tw_transit.js` | 搭火車、搭飛機（買票、報到、安檢、海關、貴賓室、登機）、機場起降 |
| `28_tw_islands.js` | 離島：澎湖、金門 |
| `30_story_tw.js` | 故事引擎：字幕、蓋章、下車互動、特技表演、過場動畫 |
| `32_tw_training.js` | 新手訓練（南迴公路） |
| `40_tw_ui.js` | HUD、導航、小地圖、短片儲存與相簿、主選單 |
| `45_island_map.js` | 右上角台灣島嶼地圖（簡化真實輪廓） |
| `47_training.js` | 訓練場（空曠場地、跑道、爬牆塔、小地圖） |
| `46_settings.js` | 設定選單：畫質、聲音、環境音驅動 |
| `90_boot.js` | 載入畫面與啟動 |
