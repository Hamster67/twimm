# Taiwan in my mind!（TWIMM）— 飛天車環島

版本：**Pre-Release 1**

社群：[Threads](https://www.threads.com/@twimm_official_tw)・[Discord](https://discord.gg/SQmFgakrUf)・[Instagram](https://www.instagram.com/twimm_official_tw)

單一網頁 3D 遊戲（Three.js），開著火箭飛天車環島台灣。線上玩：**https://twimm.netlify.app**（需要網路；也可以直接打開 `index.html`，但這樣沒辦法登入同步存檔）。

## Pre-Release 1 新功能
- **☁ 帳號・雲端同步**：用 Google 帳號登入，環島存檔和成就同步到雲端，換電腦也能接著玩
- **🛒 模組商店**：在遊戲裡瀏覽、安裝、更新 GitHub 上的模組
- **🔭 遠景（超遠視距）**：模組可以讓整座台灣看得到幾十公里外的中央山脈和海岸線（靈感來自 Distant Horizons）
- **🎮 自訂控制器**：任何接上電腦的手把都能用，可以選裝置、自己指定按鍵
- **🚗 駕駛座左右**：第一視角的駕駛座可以選左邊或右邊
- 轉動視角改成 **左鍵拖曳**；競速路線改叫 **往西／往東**（終點都是台北 101）

## 玩法
- **故事模式：** 2027/01/01 08:00 從**花蓮火車站**出發，開著火箭飛天車「TWIMCAR R1」**環島一圈**，經過 29 個點（早餐店、特技表演、**東大門夜市**、七星潭、池上、南迴、墾丁、高雄、台南、阿里山、台中、新竹、桃園、台北 101、**頭城烏石港（龜山島）、礁溪溫泉、宜蘭幾米廣場、蘇澳冷泉、清水斷崖**…），最後回到**花蓮火車站衝過終點線**。開新旅程時可以選**往南**或**往北**出發。主角稻撤入庫（日本賽車手）與好友露邊挺徹同行。沒有暴力、沒有犯罪、沒有警察追逐。
- **跟著走：** 畫面上的綠色光柱 + 上方導航列（方向箭頭與距離）+ 小地圖（綠線＝前往下一點的路）。
- **新手訓練：** 在南迴公路上練習，14 步：巡航、山路彎道、**看綠色光柱**、倒退、回儲存點、火箭、起飛、Tab 緩衝、甩尾、光圈、巨型坡道、停車、**下車找人蓋章**、回到車上（對應故事裡的三場特技表演）。不存檔、時間固定早上 10 點，T 跳過一步；訓練中不能離開南迴公路。
- **第一次玩：** 沒有存檔時選「單人遊戲」會先進行新手訓練，結業後直接從花蓮出發；有存檔時「單人遊戲」就是繼續旅程。
- **環島完成後：** 可以自由飛行、「再玩一次環島」，或回主選單。
- **隱藏彩蛋：** 地圖上沒標的地方也值得下車逛逛……

## 控制器與手機
- **控制器**：用 USB 或藍牙把手把接上電腦（Xbox、PS、Switch Pro／Joy-Con、一般手把都可以），按任一個鍵就會出現。
  - 「設定 → 控制器」可以選要用哪一個裝置，也能自己指定按鍵：用滑鼠點一下動作右邊的按鈕，再按控制器上的鍵（重複的鍵會互換；等待時 Esc 取消、Delete 清除）。
  - 左搖桿固定是轉向和前進後退，走路時右搖桿轉視角。
  - 預設：RT／ZR 油門、LT／ZL 煞車、RB／R 火箭、LB／L 緩衝、下面的鍵 起飛、右邊的鍵 對話、左邊的鍵 下車、上面的鍵 第一視角、按右搖桿 看後面、按左搖桿 喇叭、十字鍵上 回儲存點、下 倒退 5 秒、左 車內音響、右 隱藏介面、選擇鍵 地圖、開始鍵 暫停。
  - 選單：十字鍵／左搖桿移動；Switch 手把 A 確定、B 返回，其他手把下面的鍵確定、右邊的鍵返回。
- **手機**：主頁面點一下螢幕開始；遊戲中左半邊是搖桿，右邊是動作按鈕（建議橫向）。
- **Switch**：無法遊玩（Switch 內建瀏覽器沒有 WebGL）。想用 Switch 手把，請用藍牙接到電腦上。

## 主選單與設定
- 主畫面按 **Enter** 打開「開始遊戲」選單：單人遊戲、新旅程（按兩次確認，會覆蓋存檔）、新手訓練、多人遊戲、相簿、設定，單人遊戲右上角是 **模組商店**。方向鍵選擇、Enter 確定、Esc 返回。
- 主畫面左上角是更新紀錄和社群連結，右上角是 **帳號**，左下角是工作人員。
- **設定**：
  - **畫質**：預設（低／中／高／極致／電影）、解析度、陰影、視距、路邊景物、模型細緻度、雲與星空、天氣、顯示 FPS、顯示座標（回報問題用）
  - **駕駛**：駕駛座在左邊或右邊（第一視角的鏡頭和方向盤跟著換邊，只影響自己的畫面）
  - **聲音**：主音量、引擎・音效、環境音、靜音
  - **控制器**、**帳號・雲端同步**、**模組**、**車子顏色**，以及附鍵盤圖的操作說明

## 帳號・雲端同步
- 主畫面右上角「登入同步存檔」（或「設定 → 帳號・雲端同步」）用 **Google 帳號** 登入。
- 環島存檔和成就（新手訓練、颱風眼、訓練場最高分）會同步到雲端，換電腦也能接著玩。
- 登入後右上角顯示你的 **電子郵件**，點一下可以立即同步或登出；下次打開遊戲會自動登入。
- 雲端和這台電腦都有存檔時，會讓你選要用哪一個，不會直接蓋掉；之後每次存檔會自動上傳。遊玩中不會換存檔，要回主選單再同步。

## 系統
- **時間：** 真實 5 秒 ＝ 遊戲 1 分鐘（一天約 2 小時）；左上角顯示日期時間與**累計遊玩計時**（真實時間，只有新遊戲才會歸零）。白天 12–16 點人最多，晚上變少；**午夜 12 點車子自動停下（空中會等落地），自動睡到早上 8 點**。
- **天氣：** 會隨遊戲時間下雨（山區機率較高），有雨絲、陰暗天空與雨聲；設定裡可改成永遠晴天／永遠下雨。
- **環境音：** 海浪、風聲、城市、鳥叫（05–18 點）、蟬叫（08–17 點）、夜鷺（19–05 點），依所在區域變化。
- **地圖：** 環島一圈約 **200 公里**：花蓮 → 花東海岸 → 花東縱谷 → 南迴 → 墾丁 → 高雄 → 國道1號 → 台南 → 阿里山 → 台中 → 新竹 → 桃園 → 台北 → 國道5號 → 雪山隧道 → 蘭陽平原 → 宜蘭 → 蘇澳 → 蘇花改 → 花蓮。蘇花改從蘇澳出發先是**沿海高架橋**，之後才進山。大城市街道較密；花東縱谷與蘭陽平原有稻田與農舍；阿里山大瀑布；龜山島在很遠的海上只看得到輪廓。
- **火車（可以搭）：** 鐵路沿著整座本島繞一圈，普悠瑪與區間車一直在跑，到站會開車門。地面站：**花蓮、池上、新竹、宜蘭**（走進站房，跟售票處的站務員買票 → 驗票閘門刷票 → 月台候車）；地下站：**台北、桃園、台中、台南、高雄**（地面出入口買票、刷票 → 手扶梯到地下月台）。列車進站開門按 E 上車，C 切換車窗／車外視角，Enter 快轉，到站後飛天車會停在車站前面。
- **客運（可以搭）：** 花蓮、羅東、台北轉運站（路的右側）走進去按 E 在售票櫃台買票，到外面「上車處」按 E 候車，客運進站後到前門按 E 上車；Enter 快轉，C 切換視角。
- **飛機（可以搭）：** 只有**桃園國際機場**（筆直的 3 公里跑道、滑行道、停機坪、塔台，經過時看得到飛機起降）。把車停在航廈前的停車場，**走進航廈**一關一關辦：報到櫃台（選航班、出示護照、托運行李、拿登機證）→ 安全檢查（X 光機、金屬探測門）→ 證照查驗（護照蓋章）→ 免稅店、貴賓室（等登機廣播）→ 登機門掃描登機證 → 起飛、巡航、降落。沒辦完前一關，過不了下一關。高雄愛河也有工作人員駕駛的**飛天車接駁**飛澎湖。
- **澎湖：** 馬公機場有一樣完整的航廈。機場門口有**機車出租店**（W 油門、S 煞車、A/D 轉向、Shift 加速），騎機車逛馬公市區、天后宮、仙人掌冰、雙心石滬（東海岸）、玄武岩（西海岸）、跨海大橋（西北）、風車（北邊）。回程到航廈報到，可飛回桃園或搭飛天車回愛河。
- **安全：** 車與人分隔（護欄／人行道），車禍不會爆炸；撞到東西或出界會觸發**倒退特效**。
- **相簿：** 「開始遊戲 → 相簿」可回看長按 R 存下的影片（存在瀏覽器裡，最多 12 段）。
- **存檔：** 自動存檔（休息站、蓋章、每 ~1 公里）；登入帳號的話也會同步到雲端。

## 多人遊戲（不用開伺服器）
- 「開始遊戲 → 多人遊戲」（遊戲中按 **K**）：一個人按「建立房間」拿到 5 碼代碼，其他人輸入代碼按「加入」。
- 房主在房間面板選模式，大家一起開始：
  - **🏁 競速**（至少兩人）：全部人在花東縱谷排好，每個人自己選「往西」（西部：墾丁、高雄、台中）或「往東」（東部：蘇花改、宜蘭、雪隧），終點都是台北 101，兩條路一樣遠（約 100 公里）。倒數後出發，看誰最快衝過台北 101 前的終點線。上方有計時，右下角有名次，台灣地圖上藍點是對手；比賽中不能下車、對手直接穿過、路上沒有其他車。
  - **📖 故事**：照原本的環島任務（各自的存檔），開始後出現在朋友旁邊。
  - **🗺 自由**：沒有任務、不存檔，N 開地圖點藍點可以傳送到任何地方。
- 兩台車可以互撞（只會彈開，不算事故）。
- **聊天室**：按 **T** 打開右下角聊天室，Enter 送出；Esc 關閉（輸入框空的時候再按 T 也會關），聊天室開著時 Esc 不會暫停。
- **觀看對手畫面**：台灣地圖左邊的小視窗是對方的畫面（跟他的鏡頭、HUD 一樣，固定靜音）。按 **O** 放大、**Esc** 關閉；放大時 **U** 隱藏介面、**V** 強制第一視角（只影響自己）。點小視窗換人。
- 在路上看得到朋友的飛天車和名牌（下車時看得到人）、小地圖上有朋友的點，可以「傳送過去」到朋友身邊（同在本島時）。
- 瀏覽器之間直接連線（WebRTC）；少數網路環境（公司、學校、部分手機網路）可能連不上。

## 模組（Mod）
- **模組商店**：「開始遊戲」選單單人遊戲右上角，或「設定 → 模組 → 🛒 模組商店」。從 GitHub（Hamster67/twimm）讀取模組，可以搜尋、排序、切換格狀／列表，一鍵安裝、更新、解除安裝；「已安裝」分頁用開關選要使用的模組（一次一個，重新載入後套用）。想上架模組，把 `.twimm-mod.json` 放進 repo 就會出現。
- **自己做模組**：用 **TWIMM Mod Config Editor**（「設定 → 模組」可以打開）做模組，按「匯出模組 .json」存檔；在「設定 → 模組 → 📂 上傳模組」選檔案，按「重新載入以套用」。選「不使用模組」就回到原本的遊戲。
- 模組可以改：
  - **主畫面**：小標題、大標題、說明、開始提示文字、主色、背景圖
  - **模組載入畫面**：標題、提示、背景顏色／圖片、進度條顏色
  - **天氣與時間**：自動／一直晴天／一直下雨／**颱風**、固定時間
    - 颱風（風力 1～3）：強風把飛天車往旁邊推，強陣風可能把車整台吹走，下車走路也會被吹飛；海邊會有巨浪拍上海堤，漫過馬路時會把車或人沖走；山區會有土石流埋住道路，工程人員開出單線臨時便道；颱風在 3D 世界裡真的存在，開飛天車穿過眼牆衝進颱風眼就能達成心願
  - **遠景（超遠視距）**：整座台灣建一張遠景地形，霧散開，看得到 12～45 公里外的中央山脈、海岸線和公路（可選距離和精細度；夜晚、下雨、颱風、山嵐時會變短）
  - **車子顏色**
  - **地圖**：在台灣地圖上放方塊、圓柱、告示牌、樹、巨型坡道；或「關閉原本地圖」變成空白地圖自己做（單人遊戲會直接進入，沒有任務、不存檔，R 回出發點）
- 模組存在瀏覽器裡（約 4 MB 上限），背景圖會自動壓縮。
