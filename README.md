# Taiwan in my mind!（TWIMM）— 飛天車環島

版本：**Beta (6)**

社群：[Threads](https://www.threads.com/@twimm_official_tw)・[Discord](https://discord.gg/SQmFgakrUf)・[Instagram](https://www.instagram.com/twimm_official_tw)

單一網頁 3D 遊戲（Three.js）。

## 玩法
- **故事模式：** 2027/01/01 08:00 從**花蓮火車站**出發，開著火箭飛天車「TWIMCAR R1」**環島一圈**，經過 29 個點（早餐店、特技表演、**東大門夜市**、七星潭、池上、南迴、墾丁、高雄、台南、阿里山、台中、新竹、桃園、台北 101、**頭城烏石港（龜山島）、礁溪溫泉、宜蘭幾米廣場、蘇澳冷泉、清水斷崖**…），最後回到**花蓮火車站衝過終點線**。開新旅程時可以選**往南**或**往北**出發。主角稻撤入庫（日本賽車手）與好友露邊挺徹同行。沒有暴力、沒有犯罪、沒有警察追逐。
- **跟著走：** 畫面上的綠色光柱 + 上方導航列（方向箭頭與距離）+ 小地圖（綠線＝前往下一點的路）。
- **新手訓練：** 在南迴公路上練習，14 步：巡航、山路彎道、**看綠色光柱**、倒退、回儲存點、火箭、起飛、Tab 緩衝、甩尾、光圈、巨型坡道、停車、**下車找人蓋章**、回到車上（對應故事裡的三場特技表演）。不存檔、時間固定早上 10 點，T 跳過一步；訓練中不能離開南迴公路。
- **第一次玩：** 沒有存檔時按「開始新旅程」會先進行新手訓練，結業後直接從花蓮出發。有存檔時主選單最上面、高亮的是「繼續旅程」。
- **環島完成後：** 可以自由飛行、「再玩一次環島」，或回主選單。
- **隱藏彩蛋：** 地圖上沒標的地方也值得下車逛逛……

## 按鍵
| 按鍵 | 功能 |
|---|---|
| W / S / A / D | 油門（只按 W 約 200 km/h）/ 煞車倒車 / 轉向 |
| Shift | 火箭推進 |
| Tab（空中長按） | 緩衝落地，效果跟 Space 一樣但噴白煙、而且不限時 |
| Space | 起飛（上限約 45 m） |
| Tab（長按） | 空中緩衝落地；在坡道/牆面上脫離 |
| **Enter / 小鍵盤 Enter** | **倒退 5 秒**（最多退到儲存點） |
| **R（短按）** | 回到儲存點正中央 |
| **R（長按約 1 秒）** | 存下最近 30 秒影片 |
| F | 在休息站下車 / 回車上（跑的時候不行，下車時時間暫停） |
| E | 與觀眾、店家對話（可蓋章） |
| C（按住） / V | 看後面（放開回來） / 第一視角 |
| T / Enter | 跳過過場動畫 / 特技表演 |
| Y | 回看最近畫面（多視角重播，可輸出 webm） |
| P / Esc | 暫停（Backspace 回主選單） |
| **O** | **設定（畫質・聲音）**，主選單也有「設定」按鈕 |
| **P / Esc** | 暫停 ＝ 設定選單（同一個畫面，可繼續遊戲或存檔回主選單） |
| **B** | 車內音響：Spotify／YouTube 連動（貼連結）／本機音檔／內建電台 |
| **Z** | 睡覺（20:00～00:00 可用，車子先停下再睡到隔天 08:00） |
| **N** | 放大／縮小台灣島嶼地圖；放大後**點藍色的點**＝傳送回那個蓋過章的地方 |
| **U** | 隱藏／顯示畫面上的介面（GUI） |
| **F2** | 截圖（存成 PNG，不含介面） |
| 右鍵拖曳 | 轉動視角（放開後回正） |

## 系統
- **時間：** 真實 5 秒 ＝ 遊戲 1 分鐘（一天約 2 小時）；左上角顯示日期時間與**累計遊玩計時**（真實時間，1 分鐘＝1 分鐘）（只有新遊戲才會歸零）。白天 12–16 點人最多，晚上變少；**午夜 12 點車子自動停下（空中會等落地），自動睡到早上 8 點**。
- **天氣：** 會隨遊戲時間下雨（山區機率較高），有雨絲、陰暗天空與雨聲；設定裡可改成永遠晴天／永遠下雨。
- **環境音：** 鳥叫 05–18 點、蟬叫 08–17 點、夜鷺 19–05 點；自備音檔放在 `sounds/`，見 `sounds/README.txt`。
- **地圖：** 整圈約 **200 公里**（台北 → 新北 → 雪山隧道 → 蘭陽平原 → 宜蘭 → 蘇澳 → 蘇花改 → 花蓮）。蘇花改從蘇澳出發先是**沿海高架橋**，之後才進山（往北就倒過來）。大城市街道較密、外圍也有房子（斜坡、懸崖上不蓋，樹不會種進房子裡）；花東縱谷與蘭陽平原有稻田與農舍；阿里山大瀑布；龜山島在很遠的海上只看得到輪廓。
- **火車（可以搭）：** 鐵路沿著整座本島繞一圈，普悠瑪與區間車一直在跑，到站會開車門。地面站：**花蓮、池上、新竹、宜蘭**（走進站房，跟售票處的站務員買票 → 驗票閘門刷票 → 月台候車）；地下站：**台北、桃園、台中、台南、高雄**（地面出入口買票、刷票 → 手扶梯到地下月台）。列車進站開門按 E 上車，C 切換車窗／車外視角，Enter 快轉，到站後飛天車會停在車站前面。
- **飛機（可以搭）：** 只有**桃園國際機場**（筆直的 3 公里跑道、滑行道、停機坪、塔台，經過時看得到飛機起降）。把車停在航廈前的停車場，**走進航廈**一關一關辦：報到櫃台（選航班、出示護照、托運行李、拿登機證）→ 安全檢查（X 光機、金屬探測門）→ 證照查驗（護照蓋章）→ 免稅店、貴賓室（等登機廣播）→ 登機門掃描登機證 → 起飛、巡航、降落。沒辦完前一關，過不了下一關。高雄愛河也有工作人員駕駛的**飛天車接駁**飛澎湖。
- **澎湖：** 島變大了，馬公機場有一樣完整的航廈。機場門口有**機車出租店**（W 油門、S 煞車、A/D 轉向、Shift 加速），騎機車逛馬公市區、天后宮、仙人掌冰、雙心石滬（東海岸）、玄武岩（西海岸）、跨海大橋（西北）、風車（北邊）。回程到航廈報到，可飛回桃園或搭飛天車回愛河。（金門已移除）
- **座標顯示：** 設定裡可以打開「顯示座標」，畫面上方會顯示 X/Y/Z、路線位置 s（公里）、橫向距離、區域，回報問題時很好用。
- **安全：** 車與人分隔（護欄/人行道），車禍不會爆炸；撞到東西或出界會觸發**倒退特效**。
- **相簿：** 主選單 →「相簿」可回看長按 R 存下的影片（存在瀏覽器 IndexedDB，最多 12 段）。
- **存檔：** 自動存檔（休息站、蓋章、每 ~1 公里），主選單「繼續旅程」。

## 主選單
- 主頁面按 **Enter** 打開開始遊戲選單，工作人員名單在左下角。
- **開始遊戲** 選單：單人遊戲（有存檔就繼續旅程）、多人遊戲、新旅程（按兩次確認，會覆蓋存檔）、新手訓練、相簿、設定。方向鍵選擇、Enter 確定、Esc 返回。
- **設定**：畫質、聲音、車子顏色，以及附鍵盤圖的操作說明。
- **客運**：花蓮、羅東、台北轉運站（路的右側）走進去按 E 在售票櫃台買票，到外面「上車處」按 E 候車，客運進站後到前門按 E 上車；Enter 快轉，C 切換視角。
- **聊天室**（在多人房間裡）：按 **T** 打開右下角聊天室，Enter 送出；Esc 關閉（輸入框空的時候再按 T 也會關），聊天室開著時 Esc 不會暫停。
- **手把**：左搖桿轉向／前後、ZR 油門、ZL 煞車、R 火箭、L 緩衝、B（下）起飛、A（右）對話、Y（左）下車、X（上）視角、十字鍵上 儲存點、十字鍵下 倒退、－ 地圖、＋ 暫停；選單用十字鍵＋A／B。
- **Switch**：用 DNS 開出內建瀏覽器，輸入電腦的區網網址（例如 `http://192.168.x.x:8137/`）。不支援 importmap 的瀏覽器會自動轉到 `switch.html`（esbuild 打包的相容版，第一次開會預設低畫質）。
- **手機**：主頁面點一下螢幕開始；遊戲中左半邊是搖桿，右邊是動作按鈕（建議橫向）。電腦上可用 `?touch=1` 測試觸控介面。

## 多人遊戲（不用開伺服器）
- 主選單「開始遊戲」→「多人遊戲」（遊戲中按 **K**）：一個人按「建立房間」拿到 5 碼代碼，其他人輸入代碼按「加入」。
- 房主在房間面板選模式，大家一起開始：
  - **🏁 競速**（至少兩人）：全部人在花東縱谷排好，每個人自己選「往花蓮」（蘇花改、宜蘭、雪隧）或「往台中」（墾丁、高雄、台中），兩條路到台北 101 一樣遠（約 100 公里）。倒數後出發，看誰最快衝過台北 101 前的終點線。上方有計時，右下角有名次，台灣地圖上藍點是對手；比賽中不能下車、對手直接穿過、路上沒有其他車。
  - **📖 故事**：照原本的環島任務（各自的存檔），開始後出現在朋友旁邊。
  - **🗺 自由**：沒有任務、不存檔，N 開地圖點藍點可以傳送到任何地方。
- 兩台車可以互撞（只會彈開，不算事故）。
- **觀看對手畫面**：台灣地圖左邊的小視窗是對方的畫面（跟他的鏡頭、HUD 一樣，固定靜音）。按 **O** 放大、**Esc** 關閉；放大時 **U** 隱藏介面、**V** 強制第一視角（只影響自己）。點小視窗換人。
- 瀏覽器之間直接連線（WebRTC，PeerJS）；只有第一次配對會用到 PeerJS 的免費公用服務，需要網路。
- 每個人有自己的故事進度與存檔；在路上看得到朋友的飛天車和名牌（下車時看得到人）、小地圖上有朋友的點、可以聊天、可以「傳送過去」到朋友身邊（同在本島時）。
- 少數網路環境（公司、學校、部分手機網路）可能連不上。

## 模組（Mod）
- 用 [TWIMM Mod Config Editor](https://twimm.netlify.app/TWIMM_Mod_Config_Editor.html) 做模組，按「匯出模組 .json」存檔。
- 遊戲「設定 → 模組 → 📂 上傳模組」選檔案，在清單選它，按「重新載入以套用」；選「不使用模組」就回到原本的遊戲。
- 模組可以改：
  - **主畫面**：小標題、大標題、說明、開始提示文字、主色、背景圖
  - **模組載入畫面**（原本的載入畫面已經拿掉）：標題、提示、背景顏色／圖片、進度條顏色
  - **天氣與時間**：自動／一直晴天／一直下雨／**颱風**（風力 1～3：強風把飛天車往旁邊推，強陣風可能把車整台吹走；下車走路也會被風推，甚至整個人被吹飛；海邊（花東海岸、墾丁…）會有巨浪拍上海堤，爆出比路面高很多的灰白水花牆，浪漫過馬路時會把車或人沖走；山區（南迴、阿里山、蘇花）會有土石流埋住道路，工程人員開出單線臨時便道（怪手、旗手、三角錐），靠近時還可能遇到落石；颱風在 3D 世界裡真的存在，畫面上方會顯示「颱風眼 ×× km」，開飛天車穿過眼牆衝進颱風眼就能達成心願）、固定時間
  - **車子顏色**
  - **地圖**：在台灣地圖上用 s（沿著路線）／lat（離路中心）放方塊、圓柱、告示牌、樹、巨型坡道；或勾「關閉原本地圖」變成空白地圖，用 x／z 自己做（單人遊戲會直接進入，沒有任務、不存檔，R 回出發點）
- 模組存在瀏覽器裡（約 4 MB 上限），背景圖會自動壓縮。
- 範例模組：[颱風天，飛天車也有可能被吹走](https://github.com/Hamster67/twimm/blob/main/颱風天，飛天車也有可能被吹走.twimm-mod.json)
